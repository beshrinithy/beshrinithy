**[Urban Infrastructure Reporting System](https://github.com/beshrinithy)**
Full-stack civic reporting platform with role-based access (citizen/officer/admin) and real-time updates via Socket.io. RESTful APIs with JWT auth, AI-based issue classification, and Grafana dashboards.
`Next.js` `Node.js` `PostgreSQL` `Prisma` `Socket.io` `TypeScript`

**[Audit Log Dashboard](https://github.com/beshrinithy/Audit_Log_Dashboard)**
Full-stack dashboard for security engineers to upload, view, filter, search, sort, and paginate system audit logs, with all filtering/sorting/pagination performed server-side. Includes bulk upload support for 10,000+ records in a single request.
`React` `Node.js` `Express` `MongoDB`
